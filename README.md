# Amazon Clone

## Overview

This project is a responsive front-end clone of the Amazon homepage built using **HTML5** and **CSS3**. It replicates the basic layout and design of Amazon, helping developers practice modern web development concepts such as Flexbox, CSS Grid, responsive design, and component-based layouts.

## Features

* Responsive navigation bar
* Search bar with category selection
* Hero banner section
* Product cards and shopping sections
* Footer similar to Amazon
* Clean and responsive UI
* Hover effects for buttons and links

## Tech Stack

* **HTML5**
* **CSS3**

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/your-username/Amazon-Clone.git
```

2. Navigate to the project folder:

```bash
cd Amazon-Clone
```

3. Open `index.html` in your browser.
